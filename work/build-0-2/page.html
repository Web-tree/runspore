Runspore build order

The build runs on Runspore: build-0-2 is a workflow in the 0.2 format (a workflow.dot and a settings.json), run today by spore 0.1. Each wave starts one ticket run per ticket (implement, test, ship) and finishes when every ticket is merged, or closed as not planned by you. Each checkpoint is a decision you answer with go or changes; changes builds tickets made from your changes, then asks again.

How it runs

Plain spore

spore start build-0-2 --key build-0-2 starts the run once and spore worker works on it. You answer a checkpoint with spore signal <run> checkpoint-c --outcome go. This page reads the run from spore status.

On the newest spore

The fast lane builds R1 and R3 first, so spore reads this folder as it is. At any checkpoint, installing spore from main and starting spore worker again moves the build onto it, with the same database and the same run.
